# Synestra Fest — Deployment Guide (cPanel Shared Hosting)

## Overview

This project is a **Next.js 14 static export**. The build produces a plain
`out/` folder containing only HTML, CSS, JS, and images — no Node.js runtime
is needed on the server.

---

## Prerequisites

| Tool | Version |
|------|---------|
| Node.js | ≥ 18 |
| npm | ≥ 9 |

---

## Build Steps

```bash
# 1. Install dependencies (first time or after lockfile changes)
npm install

# 2. Build static export + copy .htaccess
npm run build
```

The `build` script runs `next build && cp public/.htaccess out/.htaccess`.

After a successful build you will see:

```
out/
├── index.html
├── 404.html
├── .htaccess          ← copied from public/.htaccess
├── _next/
│   ├── static/
│   │   ├── chunks/
│   │   ├── css/
│   │   └── media/
│   └── ...
├── images/
│   ├── logo.png
│   └── elements/
│       └── *.webp
└── favicon.ico
```

Total size: ~3.9 MB (before gzip).

## Uploading to cPanel

### Option A — File Manager (browser)

1. Log in to cPanel → **File Manager**.
2. Navigate to `public_html/` (or your subdomain folder).
3. Upload the entire contents of `out/` (not the folder itself) to `public_html/`.
4. Make sure `.htaccess` is included — cPanel File Manager hides dotfiles by
   default. Enable **"Show Hidden Files"** in the settings gear icon.

### Option B — FTP / SFTP

```bash
# Using rsync (recommended, skips unchanged files)
rsync -avz --delete out/ user@yourhost.com:public_html/

# Or with scp
scp -r out/. user@yourhost.com:public_html/
```

## Important Notes

### .htaccess
Next.js static export **does not copy dotfiles** from `public/` automatically.
The `npm run build` script handles this with the `cp` command. If you build
manually with `next build`, remember to run:

```bash
cp public/.htaccess out/.htaccess
```

### Trailing Slashes
`next.config.ts` has `trailingSlash: true`. The `.htaccess` rewrite rule
`^(.*)$ /$1/index.html` depends on this — do not remove either setting.

### Images
`next/image` is configured with `unoptimized: true` for static export.
All images are served as-is from `out/images/`.

### HTTPS Redirect
The `.htaccess` includes a force-HTTPS redirect. If your cPanel host does not
have an SSL certificate, remove or comment out these lines to avoid redirect
loops:

```apache
# RewriteCond %{HTTPS} off
# RewriteRule ^(.*)$ https://%{HTTP_HOST}%{REQUEST_URI} [L,R=301]
```

## Re-deploying After Changes

```bash
# Make code changes, then:
npm run build

# Re-upload out/ to cPanel (use rsync --delete to remove stale files)
rsync -avz --delete out/ user@yourhost.com:public_html/
```
